# Ece Akinci — Portfolio

Personal portfolio website built with Next.js, showcasing my journey from frontend development into AI and data science.

🔗 [eceakinci.github.io](https://eceakinci.github.io)

## Tech Stack

- **Framework:** Next.js 15
- **Styling:** Tailwind CSS
- **Content:** MDX
- **Deployment:** GitHub Pages

## Features

- Responsive design
- MDX-powered blog/course notes
- Project showcase
- Experience timeline
